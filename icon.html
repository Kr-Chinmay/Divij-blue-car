Mini Driver, Mega Values — icon builder

Every image below is drawn live from logo.js, the same file the game uses for the badge on its home screen. Click a button to save the PNG. The chequerboard shows where a file is transparent.

1. Source icon — start here

A single 1024×1024 master. Android tooling (@capacitor/assets, or Android Studio's Image Asset wizard) generates every launcher size from this one file.

2. Play Store listing

Google asks for exactly 512×512 with no transparency and no rounded corners — the store applies its own mask, so a pre-rounded icon ends up clipped twice and looks wrong.

3. Adaptive icon layers

Modern Android composes an icon from two layers and crops them to whatever shape the launcher prefers — circle, squircle, teardrop. Only the middle 66% is guaranteed to survive, so the car here is drawn smaller to keep its wheels out of the crop. Pair the foreground with a plain #ffa726 background colour.

4. Home screen icons

These two are what manifest.json asks for, so save them into the project folder under exactly these names. They are what a phone uses if the game is added to the home screen straight from the browser, without installing anything.
